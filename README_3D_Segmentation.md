# 🌳 環保局樹木專題：3D 點雲樹幹剝離與 DBH 自動量測系統開發紀錄

**開發者 / 系統架構：** Toby
**開發環境：** VS Code (`treee_VScode`) / Python / Open3D / OpenCV / Matplotlib
**最新更新日期：** 2026-08-11

## 🎯 1. 專案背景與終極目標
本專案旨在利用 JMK6 深度相機生成的 3D 去噪點雲 (`.ply`)，結合 YOLO AI 模型生成的 2D 影像分割遮罩 (`.jpg`)，實現全自動的**胸高直徑 (DBH, Diameter at Breast Height)** 精準測量。
相較於邊界模糊的 3D 高斯 (3DGS) 模型，本系統專注於處理高精度的幾何點雲，以提供具備公信力的林業/環保局測量數據。

---

## 🛠️ 2. 核心技術演進與挑戰克服 (Phase 1 - Phase 3)

### Phase 1: 跨次元剝離 (3D to 2D 反向投影)
*   **挑戰：** 原始 3D 點雲包含大量環境雜訊（地板、雜草、背景建築）。
*   **解法：** 解析相機內外參矩陣 (K, transform_matrix)，並進行 **C2W 到 W2C 的矩陣反轉**，將 300 多萬個 3D 點精準投影至 YOLO 2D 遮罩上進行過濾。
*   **工程對策：** 實作 `np.fromfile` 結合 `cv2.imdecode`，完美繞過 OpenCV 在 Windows 環境下不支援中文路徑的致命 Bug。

### Phase 2: 消除「手電筒效應」與幽靈背景
*   **挑戰：** 單純依賴 2D 遮罩會產生無限延伸的放射狀射線，將視線背後數十公尺外的物體也誤認為樹幹。
*   **解法：** 導入 **Z-Buffer 深度遮蔽過濾器**，強制剔除相機背後的無效點，並將 `OCCLUSION_TOLERANCE_M` 參數極限壓縮至 `0.05` (5 公分)，成功削薄點雲，確保只保留最表層的樹皮點雲。

### Phase 3: 地面校正與胸高切片 (Slicing)
*   **實作：** 利用 RANSAC 演算法對全場景進行平面擬合以找出水平地面，計算 Z 軸偏移量（將樹木「扶正」），精準擷取離地 `1.2m ~ 1.4m` 的「胸高切片」。
*   **清洗：** 在切片後執行 DBSCAN 密度分群，強制保留最大群集，徹底掃除邊緣離群雜訊。

## 🔬 3. 演算法瓶頸與架構躍進 (Phase 4 - Phase 5)

### Phase 4: 突破「淺弧錯覺」與幾何病態問題
*   **現象發現：** 受限於步道單向掃描的物理限制，相機僅能捕捉樹幹單側（通常 < 120°）的淺弧面。強制使用 RANSAC 或最小平方法擬合圓形時，會引發嚴重的**病態幾何 (Ill-conditioned Problem)**，導致算出的半徑暴走（曾高達 DBH 180~411 公分）。
*   **演算法分流 (Fallback 機制)：** 開發 `geo_utils/arc_coverage.py` 進行自我診斷。
    1.  **涵蓋角度 ≥ 120°：** 執行標準 RANSAC 圓形擬合。
    2.  **涵蓋角度 < 120° (觸發 🚨 警告)：** 放棄圓擬合，自動切換至**「PCA 可見寬度法 (虛擬卡尺)」**。
*   **PCA 卡尺法原理：** 利用主成分分析 (PCA) 找出點雲空間分佈變異數最大的主軸，將點雲投影後求取最大跨距，穩定計算出物理上最真實的樹幹寬度，徹底解決暴走問題。

### Phase 5: 產品級強健性與視覺化升級 (Current Version)
為提升系統的工程價值與可維護性，執行了全面性的架構重構：
1.  **模組化重構：** 遵循嚴格的 Clean Code 原則，將龐大的單一腳本拆解為 `geo_utils/`、`dbh_seg/` 等子套件，確保所有 `.py` 檔案皆維持在 100 行以內。
2.  **抗離群點升級 (Trimmed PCA)：** 在虛擬卡尺法中導入百分位數修剪 (`CALIPER_TRIM_PERCENTILE`)，捨棄極端最大/最小值，避免殘留雜訊拉長寬度。
3.  **雙軌對照視覺化：**
    *   **2D 俯視圖 (`plot2d.py`)** 與 **3D 視窗 (`viz.py`)** 升級。
    *   在觸發卡尺法時，系統會同時繪製「灰色虛線圓 (不可靠的圓擬合)」與「藍色雙箭頭 (實際採用的卡尺寬度)」，提供極具說服力的除錯與展示對照。
4.  **全自動歷史紀錄 (`export.py`)：** 每次運算結果（包含時間、DBH、涵蓋角度、使用方法）皆會自動序列化並附加至 `dbh_results.json`，利於長期追蹤與報告生成。

## 📊 4. 系統執行管線 (Pipeline) 總覽

1.  **載入與剝離：** 讀取 3D 點雲 + YOLO 2D 遮罩 ➡️ Z-Buffer 遮蔽過濾 ➡️ DBSCAN 清場。
2.  **校正與切片：** RANSAC 地面偵測 ➡️ 點雲扶正 ➡️ 擷取 1.2m~1.4m 胸高切片。
3.  **診斷與計算：** 分析弧面涵蓋角度 ➡️ 動態分流至「RANSAC 圓擬合」或「PCA 百分位卡尺法」。
4.  **視覺化與輸出：** 產出 2D 俯視報告圖 (`dbh_slice_top_down.png`) ➡️ 啟動 3D 檢視器 ➡️ 寫入 JSON 歷史紀錄。

## 💡 5. 未來展望
目前的「虛擬卡尺法」已完美解決單視角掃描的穩定度問題，且確保數值有界。若未來資料蒐集端能提供多視角照片（同一樹木前/後/左/右），系統即可輕易透過點雲融合，穩定觸發高精度的全圓 RANSAC 擬合，達到最完美的 DBH 量測。
