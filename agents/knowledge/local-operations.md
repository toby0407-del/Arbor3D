# Arbor3D 本機操作與最新狀態（2026-11-17）

## 目前發布的盤點

App 只發布兩筆實地來源：逢甲大學 `20260818092855` 共 16 棵，以及惠來公園 `20261020165350` 共 18 棵。所有 `sim*` 盤點、模擬公園季度資料、合成證據、模擬 GPX 與模擬分析快照已從正式發布目錄移除。回答目前盤點數量時，不得引用舊版 17／18 座公園、280／295 棵或 4,480／4,720 筆模擬觀測。

惠來是實際匯入批次，不是模擬盤點；但目前使用 `preview_point_cloud` 快速預覽，共偵測 52 個候選、納入 18 棵、排除 34 個。快速預覽不等同正式 Arbor3D Python／YOLO／標準 1.3 m DBH 管線。惠來東側路線是使用者繪製的近似位置，需用現場 GPX 更新。

## 需複核、人工真值與精度

需複核是品質工作清單，不是錯誤率。非標準胸高、缺測、品質未達標等資料必須維持待核對，不能用樹幹分割信心、圓周涵蓋角度或燈號替代人工真值。

有效精度配對必須同樹、同日，AI 與人工資料均確認為標準 1.3 m 胸高。有效配對為零時，MAE、RMSE、準確率與通過率都應留空；不能解讀為零誤差或百分之百準確。未出現在盤點內的樹號只能回答查無資料，不可補造樹木或數值。

## Power BI 與分析

Power BI Desktop、Analytics CSV／Excel 與 App 分析頁仍是可用的分析工具，但舊版模擬公園報表與快照不屬於目前發布盤點。當來源資料改變時必須重新產生並核對；未重新整理的 Desktop 備份只能作歷史紀錄。Power BI Desktop 本機驗證不等於 Fabric 或 Power BI Service 已發布。

## AI 助理

本機助理可使用 Microsoft Foundry Local Phi-4 mini，並先檢索本機知識與當次盤點事實。服務未啟動時使用本機證據規則，不能將規則回覆標成 Microsoft 模型答案。回答應優先使用當次盤點資料，不應把歷史模擬數據混入真實逢甲或惠來結果。

## 本機啟動

```bash
cd app
npm ci
npm run build
PORT=5174 HOST=127.0.0.1 npm start
```

開啟 `http://127.0.0.1:5174/`。`/healthz` 回傳 `ok: true` 才代表 production server 已就緒。
