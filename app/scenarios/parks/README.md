# 公園四年季度模擬資料

2026-09-23 更新：6 座新公園（上安、上德、上石、世斌、世貿、中清），加上既有 12 個公園／綠地場景，共 18 處、295 棵、4,720 筆，2022 Q3–2026 Q2 共 16 季。

只有逢甲大學保留學校掃描路線。舊有其他學校的資料檔保留，但不再綁定、顯示或新增學校示範路線。生成器只產生公園資料。

## 參考來源與假設

- 原始來源：`app/src/data/inventories/20260818092855.json`，逢甲 2026-08-18 的 16 棵真實掃描；來源檔不修改。每筆記錄保留參考掃描與樹號，manifest 記錄來源 SHA-256 與種子。
- 原始胸徑含非標準胸高與待複核數值，只作尺寸參考，沒有將它當作校準真值。模擬胸徑基準為來源值的 85%–115%。
- 年增量假設 0.35–1.15 cm，包含正常、慢速、停長及負變化複核情境。手測噪聲 SD=0.04 cm；AI 偏差=0.12 cm、噪聲 SD=0.32 cm。這些參數不代表經實驗驗證的生長模型或精度。
- 樹高公式為 `1.3 + 1.8 × sqrt(DBH)`；1.3 m 手測、量測日期、固定樹號、跨期對應、座標與 GPX 全部為模擬。不得宣稱已完成現勘、第二期真實掃描或真實精度驗證。
- 四格影像借用逢甲來源，各公園數值不對應圖片中的實際尺寸；3D 為合成示意 PLY，非該公園實測重建。
- 已有公園沿用既有 OSM 顯示線；新公園尚無已核對步道，因此地圖不繪製推測線。附帶 GPX 為中心附近的小圈示意，明確標示 SIMULATED，不能用於導航。`gps_available=false` 防止把合成座標宣稱為實測 GPS。

## 使用

App：選擇公園 → 模擬盤點 → 展開「四年季度模擬紀錄」，切換樹號、查看前後季差異，或匯出該園全部季度 CSV。點選成長狀態圖示可查看同一份季度資料的曲線。

`quarterly-SIMULATED.csv` 是全部公園的合併資料；各 GPX、生成設定及假設亦位於本目錄。所有模擬列都有 `dataset_kind=simulated`，不得與真實觀測合併計算精度 KPI。

重建（不新增學校）：

```powershell
cd app
node scripts/generate-demo-inventories.mjs
cd ..
python -m analytics.park_scenarios --out outputs/parks-simulated-new
```

分析輸出沿用既有 DimTree、DimScan、FactObservation、FactEstimate、FactGrowth、Summary 契約，與原始實測輸出分離。輸出目錄必須為空；`outputs/` 不進 Git，App 資料、CSV、GPX 與重建程式則保存在專案內。
