2026-10-28：使用已安裝的 Power BI Desktop 2.159.883.0，未登入或發佈 Power BI/Fabric。Desktop 實際刷新本機 CSV 並執行 DAX，透過 Microsoft ADOMD 用唯讀查詢匯出結果，再與原始分析資料逐表、逐指標比對，最後更新 App。

## 日後更新

1. 先在 App 保存人工量測，確認顯示「已同步」。
2. 雙擊根目錄「準備PowerBI分析.cmd」。程式讀取目前已發佈盤點及 Cosmos 人工量測，建立新的三個本機專案（真實當期／公園當期／完整季度），保留原有專案。若 Cosmos 無法連線會停止，不使用不完整資料冒充最新。
3. 在三個 Desktop 視窗按「重新整理」。不必登入；略過登入提示即可。等待查詢完成，可儲存專案，無需升級模型格式或發佈線上報表。
4. 保持 Desktop 開啟，雙擊「更新PowerBI結果.cmd」。成功後回 App 的盤點圖表區，按「讀取更新結果」。

更新腳本只連線本機 Desktop Analysis Services，執行唯讀 DAX。它核對每筆匯入資料及數量、有效實測配對、MAE／RMSE／Bias／MAPE、平均胸徑、候選碳量與模擬指標。未刷新或開錯模型時會拒絕該組結果。兩組結果分別驗證及更新；若其中一組失敗，已成功的一組可能已更新，請完成另一組刷新後再執行。

App 顯示計算時間、來源與資料版本。人工量測或來源資料變更後會標示上次分析需要重跑，不會把舊結果當成即時值。關閉 Desktop 後，已匯出的 App 結果仍可查看；「讀取更新結果」只載入成果，不會自行啟動或刷新 Desktop。
