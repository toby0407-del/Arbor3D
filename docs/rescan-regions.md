# 單木補測區域與圖層

正式 Python 量測完成後，`dbh_seg.export.export_result` 依本次截面與品質判斷，保存 `rescan_plan`、`Rescan_Overlay_Image`，並更新量測輸出目錄的 `rescan_tasks.sqlite`。主鍵為掃描 ID 與樹號，同一批重算不會重複計數。JSON 歷史保留每次量測結果；SQLite 保存目前任務。後續重新掃描若換掃描 ID，須依固定樹號另行核對，系統不會自動關閉不同批次任務。

App 的單木「影像」及「品質與補掃」顯示該樹的圖層、缺口、優先觀測方向，以及全批待處理棵數。路徑圖以橘色虛線圈標記已有補測任務的樹。可切回原始截面、下載 SVG、匯出此樹或全批 JSON。匯入發佈程序會連同 SVG 複製並重寫為相對路徑；SVG 內嵌原始 PNG，不依賴電腦上的絕對檔案路徑。

## 幾何與精度限制

- 只使用可識別、標準胸高的截面，在擬合表面附近篩選支持點，依局部 XY 每 5° 分箱。5° 是圖層解析度，並非經真值驗證的精度門檻。
- 缺失分箱合併成不重疊的連續區域，跨 0° 的缺口只記錄一次。對「所有分箱均有表面觀測」的幾何目標，這是最小缺失集合，已覆蓋區域不重複標記。最大缺口中心線優先；這是覆蓋效益代理，不是經校準的精度增益或路徑最短解。
- 操作方式為補一個區域、重新計算品質、達標即停止。尚無實驗校準的取得資料模型，不能聲稱算出精度達標所需的全域最小掃描範圍。
- 局部 +X 為 0°、逆時針增加；沒有可靠地理配準時不顯示東南西北。未分析障礙物、距離、可飛區域或遮擋可達性，須現場確認；此圖不是自動航線。
- 幾何不穩定、非標準胸高、尺度或姿態未確認時，任務轉人工複核，不猜缺口。完整角度但點數、2D 邊界或校準不合格時，也不捏造補掃方向。
- 圖層只註冊到原始胸高俯視圖，使用繪圖時保存的 `.plot.json` 軸座標與像素範圍，保留原圖不變。缺少配準資訊的歷史圖不生成圖層；未做 2D 相機投影的區域不畫在照片上。
- 既有歷史資料需重新量測以取得截面支持點與圖層配準。沒有補測證據的資料保持「尚未評估」，不批次生成假缺口。

## 驗證

`python -m unittest discover -s tests` 覆蓋跨零缺口、多缺口、未知幾何、完整截面仍待校準、SQLite 跨批主鍵及重算清除、圖層原圖嵌入。`npm test --prefix app` 包含單木對應與歷史資料無假圖層；`npm run build --prefix app` 驗證完整 App 編譯。
